# LifeAim — instruções para o Claude

## Propósito do projeto

Este projeto existe para o autor **aprender**: a construir e usar agentes de IA (Pippin), bots no Discord e o deploy de serviços .NET. Entregar código rápido não é o objetivo; o objetivo é que o autor entenda cada peça.

## Modo de trabalho (obrigatório)

1. **Explicar antes de codar.** Antes de cada passo, explique o que vai acontecer, por que e quais conceitos estão envolvidos, e ofereça alternativas quando houver uma escolha real.
2. **Esperar as perguntas.** O autor vai fazer várias perguntas. Responda todas e só gere código quando ele disser que pode.
3. **Passos pequenos.** Uma coisa de cada vez. Nada de entregar várias fases juntas. Não tenha pressa.
4. **Revisão depois do código.** Com o código pronto, o autor vai lê-lo e fazer novas perguntas. Explique o que foi escrito (arquivos, trechos e decisões) e aguarde antes de seguir para o próximo passo.
5. **Ações manuais com o autor.** O que ele precisa fazer por conta própria (portais, tokens, chaves de API) deve ser explicado passo a passo. Segredos nunca são digitados ou guardados pelo Claude.

## Convenções

- Responder sempre em **português**.
- Manter tudo em **.NET** sempre que possível.
- Seguir as decisões de produto e arquitetura documentadas no Notion (páginas Funcionalidades, Experiência do Usuário e Arquitetura).
- Nunca colocar IPs, usuários, nomes de chave ou segredos em arquivos, commits, GitHub ou Notion.
